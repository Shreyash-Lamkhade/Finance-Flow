# FinanceFlow – Internship Project Full Context Document
# For use with Claude to generate Internship Report

---

## SECTION 1 — PROJECT OVERVIEW

**Project Name:** FinanceFlow – Personal Finance Tracker
**Course:** Cisco Networking Academy – JavaScript Essentials 1 & 2
**Technology Stack:** HTML5, CSS3, Vanilla JavaScript (ES6 Modules)
**Type:** Frontend Web Application (no backend, no framework)
**Run Method:** Open index.html directly in browser. Uses Chart.js via CDN.

**Purpose:**
FinanceFlow is a personal finance dashboard that allows users to track income and expenses, visualize spending patterns through charts, set category-wise budget limits, and filter transactions by date range or time period. The project was built as a practical demonstration of all JavaScript Essentials 1 and 2 concepts taught in the Cisco Networking Academy curriculum.

## SECTION 3 — FEATURES LIST

1. **Dashboard Stats** – Real-time cards showing Total Balance, Income, Expenses, Savings
2. **Add / Edit / Delete Transactions** – Full CRUD with form validation and confirmation modal
3. **Search & Filter** – Live search by title/category; filter by type (income/expense)
4. **Period Filters** – Filter transactions for "This Week" or "This Month"
5. **Date Range Filter** – Custom From/To date range picker
6. **Analytics Charts** – Doughnut chart (expenses by category) + Tableau-style bar chart (income vs expense)
7. **Budget Limits per Category** – Set monthly spending cap per category, visual progress bar (green/orange/red)
8. **Dark / Light Theme Toggle** – Persisted in localStorage, affects charts too
9. **localStorage Persistence** – All transactions, budgets, and theme survive page reload
10. **Toast Notifications** – Non-blocking feedback messages for add/update/delete actions
11. **Delete Confirmation Modal** – Prevents accidental deletion
12. **Responsive Design** – Works on mobile, tablet, desktop

## SECTION 5 — MODULE-BY-MODULE EXPLANATION

### 5.1 transactionClass.js
Defines the `Transaction` ES6 class. This is the data model of the app.
- **Constructor** takes title, amount, category, type, date, and optional id
- `id` is auto-generated using `Date.now().toString()` if not provided
- `formatAmount()` – instance method returning formatted currency string with +/- prefix
- `toJSON()` – converts instance to plain object for JSON storage
- `fromJSON()` – static method to recreate a Transaction from a stored plain object
- Also exports `TYPES` object and `CATEGORIES` array as constants

### 5.2 transaction.js
Business logic layer. Maintains the `transactions` array in module scope.
- `getTransactions()` / `setTransactions()` – getter and setter using map + fromJSON
- `validateTransaction()` – input validation, returns error string or empty string
- `addTransaction()` – validates then pushes new Transaction instance
- `updateTransaction()` – validates, uses findIndex to replace in array
- `deleteTransaction()` – uses filter to remove by id
- `getTransactionById()` – uses find method
- `filterTransactions()` – multi-filter: period (week/month), date range, type, search text, sorted by date
- `calculateStats()` – uses filter + reduce to compute income, expenses, balance, savings
- `getExpensesByCategory()` – uses for loop to group expenses into object

### 5.3 storage.js
Handles all localStorage operations with JSON serialization and try-catch error handling.
- `saveTransactions()` / `loadTransactions()` – JSON.stringify / JSON.parse with error handling
- `saveTheme()` / `loadTheme()` – stores user's dark/light preference

### 5.4 budget.js
Manages per-category spending limits stored separately in localStorage.
- `loadBudgets()` / `saveBudgets()` – reads/writes `{ category: limit }` object
- `setBudgetLimit()` – loads, updates one key, saves back
- `removeBudgetLimit()` – uses `delete` operator on object key
- `checkBudgets()` – iterates budgets with `for...in`, computes percent, builds alert array, sorts

### 5.5 ui.js
All DOM interaction. Reads from the DOM and writes to the DOM. No business logic.
- `initElements()` – caches all DOM elements in the `els` object
- `populateCategories()` – builds category `<option>` elements using map + template literals
- `setDefaultDate()` – computes today's date and fills the date input
- `updateStats()` – updates four stat card values
- `renderTransactions()` – builds the `<li>` list using forEach + innerHTML template literals, attaches edit/delete listeners
- `fillEditForm()` / `resetForm()` – form state management
- `showToast()` / `showDeleteModal()` / `showFormError()` – UI feedback
- `applyTheme()` – sets data-theme attribute on html element
- `renderBudgets()` – builds progress bar HTML for each budget entry, attaches remove listeners

### 5.6 charts.js
Chart.js integration with Tableau 10 color palette.
- `getChartTheme()` – reads current data-theme and returns matching colors
- `updatePieChart()` – doughnut chart of expenses grouped by category
- `updateBarChart()` – Tableau-style vertical bar chart with value labels drawn on canvas after animation, dashed grid lines, abbreviated tick labels
- Both charts are destroyed and recreated on every update (Chart.js pattern)

### 5.7 app.js
Orchestrator / entry point. Imports all modules and connects them.
- Declares module-level state: `deleteTargetId`, `currentTheme`
- `refreshUI()` – called after every data change; reads all filter values, calls calculateStats, filterTransactions, renderTransactions, updateCharts, refreshBudgets, saveTransactions
- `handleSubmit()` – decides add vs update based on hidden editId field
- `handleEdit()` / `handleDeleteRequest()` / `handleConfirmDelete()` – CRUD event chain
- `toggleTheme()` – switches theme, saves, re-renders charts
- `handleBudgetSubmit()` – reads budget form, calls setBudgetLimit
- `handlePeriodChange()` / `handleDateRangeChange()` – mutual exclusion between period and date range filters
- `init()` – bootstraps everything on DOMContentLoaded

### transactionClass.js

```javascript
/**
 * transactionClass.js
 * ES6 Class demonstrating: Classes, Constructors, Methods, Objects
 */

export const TYPES = { INCOME: 'income', EXPENSE: 'expense' };

export const CATEGORIES = [
  'Salary', 'Freelance', 'Food', 'Shopping', 'Travel',
  'Bills', 'Entertainment', 'Health', 'Education', 'Other'
];

export class Transaction {
  constructor(title, amount, category, type, date, id = null) {
    this.id = id || Date.now().toString();
    this.title = title;
    this.amount = parseFloat(amount);
    this.category = category;
    this.type = type;
    this.date = date;
  }

  formatAmount() {
    const prefix = this.type === TYPES.INCOME ? '+' : '-';
    return `${prefix}₹${this.amount.toFixed(2)}`;
  }

  toJSON() {
    return { id: this.id, title: this.title, amount: this.amount,
             category: this.category, type: this.type, date: this.date };
  }

  static fromJSON(obj) {
    return new Transaction(obj.title, obj.amount, obj.category, obj.type, obj.date, obj.id);
  }
}
```

```javascript
/**
 * transaction.js
 * Business logic: validation, CRUD, filtering, stats
 * Demonstrates: Functions, Arrow Functions, Arrays, if-else, Array Methods, Date Object
 */

import { Transaction, TYPES, CATEGORIES } from './transactionClass.js';

let transactions = [];

export const getTransactions = () => transactions;

export const setTransactions = (data) => {
  transactions = data.map(obj => Transaction.fromJSON(obj));
};

export const validateTransaction = (title, amount, category, type, date) => {
  if (!title || title.trim() === '') return 'Title is required.';
  if (!amount || parseFloat(amount) <= 0) return 'Amount must be greater than zero.';
  if (!category) return 'Please select a category.';
  if (!type) return 'Please select a type.';
  if (!date) return 'Date is required.';
  return '';
};

export const addTransaction = (title, amount, category, type, date) => {
  const error = validateTransaction(title, amount, category, type, date);
  if (error) return { success: false, error };
  const tx = new Transaction(title, amount, category, type, date);
  transactions.push(tx);
  return { success: true, transaction: tx };
};

export const updateTransaction = (id, title, amount, category, type, date) => {
  const error = validateTransaction(title, amount, category, type, date);
  if (error) return { success: false, error };
  const index = transactions.findIndex(tx => tx.id === id);
  if (index === -1) return { success: false, error: 'Transaction not found.' };
  transactions[index] = new Transaction(title, amount, category, type, date, id);
  return { success: true };
};

export const deleteTransaction = (id) => {
  transactions = transactions.filter(tx => tx.id !== id);
};

export const getTransactionById = (id) => transactions.find(tx => tx.id === id);

const getWeekStart = () => {
  const now = new Date();
  const day = now.getDay();
  const diff = (day === 0 ? -6 : 1 - day);
  const monday = new Date(now);
  monday.setDate(now.getDate() + diff);
  monday.setHours(0, 0, 0, 0);
  return monday;
};

const getMonthStart = () => {
  const now = new Date();
  return new Date(now.getFullYear(), now.getMonth(), 1);
};

export const filterTransactions = (search = '', typeFilter = 'all', dateFrom = '', dateTo = '', period = 'all') => {
  let result = [...transactions];

  if (period === 'week') {
    const weekStart = getWeekStart();
    result = result.filter(tx => new Date(tx.date) >= weekStart);
  } else if (period === 'month') {
    const monthStart = getMonthStart();
    result = result.filter(tx => new Date(tx.date) >= monthStart);
  }

  if (dateFrom) {
    const from = new Date(dateFrom);
    result = result.filter(tx => new Date(tx.date) >= from);
  }
  if (dateTo) {
    const to = new Date(dateTo);
    result = result.filter(tx => new Date(tx.date) <= to);
  }

  if (typeFilter === TYPES.INCOME) {
    result = result.filter(tx => tx.type === TYPES.INCOME);
  } else if (typeFilter === TYPES.EXPENSE) {
    result = result.filter(tx => tx.type === TYPES.EXPENSE);
  }

  if (search.trim()) {
    const term = search.toLowerCase();
    result = result.filter(tx =>
      tx.title.toLowerCase().includes(term) ||
      tx.category.toLowerCase().includes(term)
    );
  }

  result.sort((a, b) => new Date(b.date) - new Date(a.date));
  return result;
};

export const calculateStats = () => {
  const income = transactions
    .filter(tx => tx.type === TYPES.INCOME)
    .reduce((sum, tx) => sum + tx.amount, 0);
  const expenses = transactions
    .filter(tx => tx.type === TYPES.EXPENSE)
    .reduce((sum, tx) => sum + tx.amount, 0);
  const balance = income - expenses;
  const savings = balance > 0 ? balance : 0;
  return { income, expenses, balance, savings };
};

export const getExpensesByCategory = () => {
  const expenseTxs = transactions.filter(tx => tx.type === TYPES.EXPENSE);
  const grouped = {};
  for (let i = 0; i < expenseTxs.length; i++) {
    const cat = expenseTxs[i].category;
    grouped[cat] = (grouped[cat] || 0) + expenseTxs[i].amount;
  }
  return grouped;
};

export { CATEGORIES, TYPES };
```

```javascript
  } catch (error) {

    return [];
  }
};
```

```javascript
const BUDGET_KEY = 'financeflow_budgets';

export const loadBudgets = () => {
  try {
    const raw = localStorage.getItem(BUDGET_KEY);
    return raw ? JSON.parse(raw) : {};
  } catch (e) { return {}; }
};

export const saveBudgets = (budgets) => {
  try {
    localStorage.setItem(BUDGET_KEY, JSON.stringify(budgets));
  } catch (e) { console.error('Failed to save budgets:', e.message); }
};

export const setBudgetLimit = (category, limit) => {
  const budgets = loadBudgets();
  budgets[category] = parseFloat(limit);
  saveBudgets(budgets);
};

export const removeBudgetLimit = (category) => {
  const budgets = loadBudgets();
  delete budgets[category];
  saveBudgets(budgets);
};

export const checkBudgets = (expensesByCategory) => {
  const budgets = loadBudgets();
  const alerts = [];

  for (const category in budgets) {
    const limit = budgets[category];
    const spent = expensesByCategory[category] || 0;
    const percent = limit > 0 ? Math.round((spent / limit) * 100) : 0;
    const exceeded = spent > limit;
    alerts.push({ category, spent, limit, percent, exceeded });
  }

  alerts.sort((a, b) => {
    if (a.exceeded && !b.exceeded) return -1;
    if (!a.exceeded && b.exceeded) return 1;
    return b.percent - a.percent;
  });

  return alerts;
};
```

```javascript
  const stats = calculateStats();
  updateStats(stats);
  const search = els.searchInput.value;

  const dateTo = els.dateTo.value;

  saveTransactions(data);

  e.preventDefault();
  const { id, title, amount, category, type, date } = getFormData();

    if (result.success) showToast('Transaction updated!');
  } else {
    result = addTransaction(title, amount, category, type, date);
    if (result.success) showToast('Transaction added!');

  if (!result.success) { showFormError(result.error); return; }
  resetForm();

    els.dateTo.value = '';
```

## SECTION 8 — KEY LEARNING OUTCOMES

1. **Modular Code Design** – Separated concerns into 7 files, each with a single responsibility. Learned how ES6 import/export keeps code organized and reusable.

2. **Object-Oriented Programming** – Designed the `Transaction` class with a constructor, instance methods, and a static factory method. Each transaction in the app is an actual object instance.

3. **Functional Array Methods** – Used `.map()`, `.filter()`, `.reduce()`, `.find()`, `.findIndex()`, and `.sort()` extensively instead of manual loops to write cleaner, more readable code.

4. **Data Persistence** – Learned to serialize JavaScript objects to JSON strings for localStorage storage and deserialize them back into class instances on load, with error handling using try-catch.

5. **DOM Manipulation** – Built a fully dynamic UI without any framework. All HTML for the transaction list and budget bars is generated with JavaScript using template literals and `innerHTML`.

6. **Event-Driven Architecture** – The entire app responds to user events. Learned how to attach event listeners, read form data, prevent default behavior, and propagate changes through the UI.

7. **Date Handling** – Used the JavaScript Date object to implement weekly and monthly filters, computing the Monday of the current ISO week and the first day of the current month dynamically.

8. **Separation of Logic and UI** – `transaction.js` never touches the DOM; `ui.js` never modifies the data array. This clean separation made debugging significantly easier.

const BUDGET_KEY = 'financeflow_budgets';

/** Load budgets from localStorage – returns plain object { category: limit } */

  } catch (e) {
    console.error('Failed to load budgets:', e.message);
    return {};
  }
};

/** Save budgets object to localStorage */
export const saveBudgets = (budgets) => {
  try {
    localStorage.setItem(BUDGET_KEY, JSON.stringify(budgets));
  } catch (e) {
    console.error('Failed to save budgets:', e.message);
  }
};

/** Set a budget limit for a category */
export const setBudgetLimit = (category, limit) => {
  const budgets = loadBudgets();
  budgets[category] = parseFloat(limit);
  saveBudgets(budgets);
};

/** Remove budget limit for a category */
export const removeBudgetLimit = (category) => {
  const budgets = loadBudgets();
  delete budgets[category];
  saveBudgets(budgets);
};

/**
 * Check all categories against their budgets.
 * Returns array of { category, spent, limit, percent, exceeded }
 * Demonstrates: for...in loop, objects, arithmetic operators
 */
export const checkBudgets = (expensesByCategory) => {
  const budgets = loadBudgets();
  const alerts = [];

  for (const category in budgets) {
    const limit = budgets[category];
    const spent = expensesByCategory[category] || 0;
    const percent = limit > 0 ? Math.round((spent / limit) * 100) : 0;
    const exceeded = spent > limit;

    alerts.push({ category, spent, limit, percent, exceeded });
  }

  // Sort: exceeded first, then by percent descending
  alerts.sort((a, b) => {
    if (a.exceeded && !b.exceeded) return -1;
    if (!a.exceeded && b.exceeded) return 1;
    return b.percent - a.percent;
  });

  return alerts;
};

export const validateTransaction = (title, amount, category, type, date) => {
  if (!title || title.trim() === '') return 'Title is required.';
  if (!amount || parseFloat(amount) <= 0) return 'Amount must be greater than zero.';
  if (!category) return 'Please select a category.';
  if (!type) return 'Please select a type.';
  if (!date) return 'Date is required.';
  return '';
};

/** Add a new transaction */

  const error = validateTransaction(title, amount, category, type, date);
  if (error) return { success: false, error };

  const tx = new Transaction(title, amount, category, type, date);
  transactions.push(tx);
  return { success: true, transaction: tx };
};

/** Update existing transaction by ID */
export const updateTransaction = (id, title, amount, category, type, date) => {
  const error = validateTransaction(title, amount, category, type, date);
  if (error) return { success: false, error };

  const index = transactions.findIndex(tx => tx.id === id); // find method
  if (index === -1) return { success: false, error: 'Transaction not found.' };

  transactions[index] = new Transaction(title, amount, category, type, date, id);
  return { success: true };
};

  monday.setHours(0, 0, 0, 0);
  return monday;
};

/**
 * Get the first day of the current month
 * Demonstrates: Date object, setDate
 */
const getMonthStart = () => {
  const now = new Date();
  return new Date(now.getFullYear(), now.getMonth(), 1);
};

/** Filter & search transactions */
export const filterTransactions = (search = '', typeFilter = 'all', dateFrom = '', dateTo = '', period = 'all') => {
  let result = [...transactions];

  // --- Period filter (this week / this month) ---
  if (period === 'week') {
    const weekStart = getWeekStart();
    result = result.filter(tx => new Date(tx.date) >= weekStart);
  } else if (period === 'month') {
    const monthStart = getMonthStart();
    result = result.filter(tx => new Date(tx.date) >= monthStart);
  }

  // --- Date range filter using Date object comparisons ---
  if (dateFrom) {
    const from = new Date(dateFrom);
    result = result.filter(tx => new Date(tx.date) >= from);
  }
  if (dateTo) {
    const to = new Date(dateTo);
    result = result.filter(tx => new Date(tx.date) <= to);
  }

  // Filter by type using if-else
  if (typeFilter === TYPES.INCOME) {
    result = result.filter(tx => tx.type === TYPES.INCOME);
  } else if (typeFilter === TYPES.EXPENSE) {
    result = result.filter(tx => tx.type === TYPES.EXPENSE);
  }

  // Search by title or category
  if (search.trim()) {
    const term = search.toLowerCase();
    result = result.filter(tx =>
      tx.title.toLowerCase().includes(term) ||
      tx.category.toLowerCase().includes(term)
    );
  }

  // Sort by date (newest first) using Date object
  result.sort((a, b) => new Date(b.date) - new Date(a.date));
  return result;
};

/** Calculate dashboard stats using reduce */
export const calculateStats = () => {
  const income = transactions
    .filter(tx => tx.type === TYPES.INCOME)
    .reduce((sum, tx) => sum + tx.amount, 0);

  const expenses = transactions
    .filter(tx => tx.type === TYPES.EXPENSE)
    .reduce((sum, tx) => sum + tx.amount, 0);

  const balance = income - expenses;
  const savings = balance > 0 ? balance : 0;

  return { income, expenses, balance, savings };
};

/** Get expense totals grouped by category (for pie chart) */
export const getExpensesByCategory = () => {
  const expenseTxs = transactions.filter(tx => tx.type === TYPES.EXPENSE);
  const grouped = {};

  // Loop through expenses and group by category
  for (let i = 0; i < expenseTxs.length; i++) {
    const cat = expenseTxs[i].category;
    grouped[cat] = (grouped[cat] || 0) + expenseTxs[i].amount;
  }
  return grouped;
};

// Constants for transaction types
export const TYPES = { INCOME: 'income', EXPENSE: 'expense' };

// Array of available categories
export const CATEGORIES = [
  'Salary', 'Freelance', 'Food', 'Shopping', 'Travel',
  'Bills', 'Entertainment', 'Health', 'Education', 'Other'
];

/**
 * Transaction class – each transaction is an object instance
 */
export class Transaction {
  constructor(title, amount, category, type, date, id = null) {
    this.id = id || Date.now().toString(); // unique ID using Date
    this.title = title;
    this.amount = parseFloat(amount);
    this.category = category;
    this.type = type;
    this.date = date;
  }

  // Method: format amount with currency symbol
  formatAmount() {
    const prefix = this.type === TYPES.INCOME ? '+' : '-';
    return `${prefix}₹${this.amount.toFixed(2)}`;
  }

  // Method: convert instance to plain object for JSON storage
  toJSON() {
    return {
      id: this.id,
      title: this.title,
      amount: this.amount,
      category: this.category,
      type: this.type,
      date: this.date
    };
  }

  // Static method: create Transaction from stored object
  static fromJSON(obj) {
    return new Transaction(obj.title, obj.amount, obj.category, obj.type, obj.date, obj.id);
  }
}
