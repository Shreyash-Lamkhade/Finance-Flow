# FinanceFlow – Personal Finance Tracker

A modern personal finance dashboard built with **HTML5, CSS3, and Vanilla JavaScript** for Cisco Networking Academy JavaScript Essentials 1 & 2.

## Features
- Dashboard with Balance, Income, Expenses, Savings
- Add / Edit / Delete transactions
- Search & filter transactions
- Chart.js analytics (Pie + Bar charts)
- Local Storage persistence
- Dark/Light mode toggle
- Responsive glassmorphism UI

## How to Run
1. Open `index.html` in any modern browser (Chrome recommended)
2. No server or installation needed — uses Chart.js CDN
